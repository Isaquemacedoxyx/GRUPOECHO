# IVS — IndieVibeSystem

Projeto acadêmico desenvolvido pela **Equipe ECHO**, com foco no levantamento, análise e documentação dos requisitos de um sistema.

O **IndieVibeSystem (IVS)** é uma proposta conceitual de aplicativo mobile voltado à descoberta de artistas independentes, reprodução de músicas e apoio financeiro aos músicos.

## Objetivo do projeto

Documentar a proposta do sistema, identificando suas necessidades, requisitos, regras de negócio e comportamentos esperados. O trabalho busca organizar e especificar como a solução deverá funcionar, considerando os diferentes usuários e suas necessidades.

## Escopo da proposta

O IndieVibeSystem prevê:

- Descoberta de artistas independentes e novas músicas;
- Reprodução de músicas;
- Recomendações personalizadas;
- Busca e filtros de artistas;
- Acompanhamento de artistas e notificações;
- Visualização de perfis de músicos;
- Apoio financeiro aos artistas por Pix e cartão.

## Atividades desenvolvidas

O trabalho contempla atividades relacionadas à análise e documentação de sistemas:

- **Levantamento de requisitos:** identificação das necessidades e expectativas dos usuários.
- **Requisitos funcionais:** especificação das funcionalidades previstas para o sistema.
- **Requisitos não funcionais:** definição de critérios de desempenho, segurança, usabilidade e continuidade.
- **Regras de negócio:** documentação das condições e restrições que orientam o funcionamento da solução.
- **Casos de uso:** descrição das interações entre os usuários e o sistema, incluindo fluxos principais e alternativos.
- **Matriz de rastreabilidade:** organização das relações entre requisitos, casos de uso e regras de negócio.
- **Modelagem e diagramas:** representação dos processos e comportamentos previstos para o sistema.

## Documentação

O principal artefato produzido é a Especificação de Requisitos de Software (ERS), versão 1.0, que reúne a descrição geral do produto, os requisitos, as regras de negócio, os casos de uso e os diagramas complementares.
